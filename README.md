
# Nutritional Analysis

## Project Overview
This project focuses on analyzing nutritional data using Microsoft Power BI to explore nutritional values and identify patterns.

## Technology Used
- Microsoft Power BI
- Data Visualization
- Interactive Dashboards

## Project Objectives
- Analyze nutritional information.
- Explore macronutrients and micronutrients.
- Compare nutritional values.
- Present insights through interactive visualizations.
